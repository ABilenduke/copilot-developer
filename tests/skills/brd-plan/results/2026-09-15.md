## Efficiency and limits

Core instructions decreased from **3,040 to 986 whitespace-delimited words**. Supporting references
load selectively; their words are additional when read. These are source-size measurements, not
token savings or latency measurements. The fresh CLI smoke recorded 35,878 input tokens, 28,032
cached input tokens, and 1,138 output tokens; there is no matched baseline token trace for comparison.

The final probe asked four initial question prompts across the cases (three for search and one for
retention), compared with five in the ordinary control. Compound questions and necessary follow-ups
make this a coarse observation. BRD outputs are substantially longer than the ordinary control;
the tradeoff is explicit traceability and handoff structure rather than uniformly shorter responses.

The full-suite probes used one agent per variant with visible scripted answers and shared context
between cases. They are preliminary behavioral checks, not statistically independent trials. Ambient
repository instructions were present, and source evidence for hypothetical applications was supplied
rather than inspected. Native Plan Mode write behavior was a scenario constraint; its actual UI,
structured question controls, and enforcement were not exercised. The focused two-turn retest reduces
answer leakage for one case but does not remove those broader limits.
